## 1. 研发管理准则与通用交付定义 (Definition of Done)

为确保“地下室弱网可用”、“单手极速触控”以及“数据绝对不丢”的核心产品标准，所有需求在合并或提测前必须满足如下 **DoD (完成定义)**：

1. **功能完整度**：代码逻辑严格对照 [FRS 功能需求说明书](file:///C:/Users/Administrator/.gemini/antigravity-ide/brain/fa0f72bc-8851-44f5-a38d-3f0c0dd5c955/functional_requirements_specification.md) 落地，包含正常流与异常边界。
2. **离线与弱网兼容 (Local-First)**：Chrome DevTools 开启 `Offline` 模式下，所有本地 CRUD 必须正常运行，无阻断弹窗与死锁。
3. **触控与性能门禁**：
   - 关键操作（勾选打卡、切换动作、计时器唤醒）在低端移动设备渲染帧率稳定 $\ge 55\text{ FPS}$；
   - 核心触控靶区尺寸不低于 $48 \times 48\text{ px}$。
4. **单元测试与类型完备**：核心数学计算（1RM、杠片贪心分配、超负荷推算）测试覆盖率达到 100%，TypeScript 无 `any` 降级逃避检查。
