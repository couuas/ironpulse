## 一、 设计哲学与美学定位 (Aesthetic Manifesto)

IronPulse 的视觉基调定位于**“硬核极客工业美学 (Cyber Iron & Stealth Precision)”**，拒绝传统健身 App 廉价的红色塑料感、花哨卖课弹窗与粗糙的大色块。整体观感向 **Linear、Raycast、Vercel** 等全球顶尖生产力工具看齐：

1. **暗影精密 (Stealth Depth)**：摒弃简单平庸的单色纯黑（`#000`），采用多层级暗色微梯度（Micro-Elevations）与细微边框光效（`1px rgba(255,255,255,0.08)`），营造高端录音室或精密仪表的深邃层次。
2. **高能荧光锚点 (Kinetic Accents)**：在极度克制的暗色画布上，仅使用**赛博荧光绿 (Kinetic Green)**、**电金徽章色 (Electrum Gold)** 与**冷调科技蓝 (Cobalt Tech)** 作为数据突破与焦点引导。
3. **数值等宽排版 (Tabular Data Precision)**：力量训练核心是数据（重量、次数、容量、1RM、秒数）。所有数据字符统一采用等宽字体（`font-variant-numeric: tabular-nums`），彻底消除数字跳动带来的界面抖动。
4. **真正的双模态体验 (Dual-Mode UX)**：
   - **移动端**：健身房场景专用。大靶心触控、单手拇指热区、极简信息密度、秒表级反应；
   - **桌面端**：周日复盘与宏观计划排课工作台。**拒绝把手机页面拉伸成 800px 居中大白条**，充分利用 1440px+ 屏幕宽度，采用“多列看板 + 侧边深度检查器 (Inspector) + 实时肌肉图与负荷图表”的高密布局。

## 二、 色彩系统与层级设计 (Color Palette & Elevation)

### 2.1 表面层级体系 (Elevation Layers)

```
[Level 3: 弹窗/抽屉/浮层]      #1A1E2B (高斯模糊 20px, 投影 0 20px 50px rgba(0,0,0,0.6))
         ▲
[Level 2: 动作卡片/面板]       #13161F (1px 极细微边框 rgba(255,255,255,0.07))
         ▲
[Level 1: 桌面主内容画布]      #0D0F14
         ▲
[Level 0: 背景画布与侧边栏]    #08090C (最底层深空黑)

| `--bg-canvas` | `#0D0F14` | 主内容展示区域底色 |
| `--bg-surface` | `#13161F` | 动作卡片、数据仪表盘、模板卡片主表面 |

| `--bg-glass` | `rgba(19, 22, 31, 0.82)` | 悬浮倒计时栏、毛玻璃导航栏（Backdrop Filter: blur(16px)） |

| `--border-strong` | `rgba(255, 255, 255, 0.14)`| 输入框聚焦前、卡片悬停边缘 |

### 2.2 信号指示与强调色 (Accent System)

```
Kinetic Green     Electrum Gold     Cobalt Blue      Crimson Flare
  #22C55E           #F59E0B           #3B82F6          #F43F5E
  (完成/容量)       (1RM/PR突破)       (技术参数/协同)  (力竭/超限告警)
```

- **Kinetic Green (力量荧光绿)**：`#22c55e`（Glow: `rgba(34, 197, 94, 0.25)`）
  - *心理映射*：安全完成、有效容量累积、心率达标。
- **Electrum Gold (电金)**：`#f59e0b`（Glow: `rgba(245, 158, 11, 0.3)`）
  - *心理映射*：创下历史 PR、新动作解锁、里程碑突破。
- **Cobalt Blue (科技蓝)**：`#3b82f6`
  - *心理映射*：协同肌群、冷色区间、递减组 (Drop Set) 标记。
- **Crimson Flare (力竭红)**：`#f43f5e`
  - *心理映射*：力竭组 (Failure Set)、倒计时最后 5 秒警报、删除危险操作。

## 三、 字体层级与精密数值排版 (Typography System)

### 3.1 字体栈选型
- **正文与UI字体**：`Plus Jakarta Sans` / `Inter`, `-apple-system`, `BlinkMacSystemFont`, `Segoe UI`, `sans-serif`
  - *特质*：宽阔的 x 高、清晰的字母区分度，在深色背景下抗眩光。
- **数据与计数等宽字体**：`JetBrains Mono`, `SF Mono`, `monospace`
  - *特质*：大字号下的工业美感，数字等宽（`tabular-nums`），保证重量与时间列垂直严密对齐。

### 3.2 字阶规范

| 级别 Token | 字号 / 行高 | 字重 | 应用场景 |
| :--- | :--- | :--- | :--- |
| `text-display` | `38px / 44px` | 800 (ExtraBold) | 桌面端主页欢迎标语、倒计时主数字 |
| `text-h1` | `24px / 32px` | 800 (ExtraBold) | 页面大标题（如“分化训练计划”、“动作库”） |
| `text-h2` | `18px / 26px` | 700 (Bold) | 模块副标题、动作卡片动作名 |
| `text-h3` | `15px / 22px` | 600 (SemiBold) | 组列表头、次级卡片标题 |
| `text-body` | `14px / 20px` | 400 ~ 500 | 动作要点说明、辅助性文本 |
| `text-caption`| `12px / 16px` | 500 (Medium) | Ghost 历史虚影提示、肌群标签 |
| `text-mono` | `13px ~ 15px` | 700 (Bold) | 重量 (kg)、次数 (reps)、RPE、耗时秒表 |

## 四、 桌面端工作台重构设计规范 (Desktop Workstation Layout)

针对屏幕宽度 $\ge 1024\text{px}$（iPad横屏、Mac/PC 笔记本、4K显示器），彻底摒弃手机拉伸模式，采用**“双栏工作台 (Split-Pane Workstation)”**：

```
+-------------------------------------------------------------------------------------------------------+
|  ⚡ IronPulse     [计划]  [动作库]  [数据分析]  [体态追踪]                 [搜索 ⌘K]  [🔥 正在进行 00:42:15]  |
+-------------------------------------------------------------------------------------------------------+
|  ◀ 导航坞 (240px)   |  中央核心区：训练执行流 (58%)                 |  右侧深度巡视器 (Inspector) (42%)        |

|  • 今日推荐 (推力)  |  +-----------------------------------------+ |  +----------------------------------+ |
|  • PPL 周期计划     |  | 动作 1: 杠铃平板卧推        [配重] [...] | |  | 🧠 渐进超负荷推算 (Overload Advisor) | |

+-------------------------------------------------------------------------------------------------------+

### 4.1 桌面端布局三层结构
1. **左侧导航坞 (Navigation Dock - 240px 固宽)**：
   - 常驻左侧，收纳核心页面切换、当前进行中的训练微型进度卡片与常用计划快捷入口；
   - 底部常驻“数据导入/导出备份”与“偏好设置”。
2. **中间打卡流 (Active Stream - 弹性主工作区)**：
   - 集中展示当前动作序列与打卡表格；
   - 支持键盘快捷键（如按 `Enter` 下一组，方向键微调重量）；
   - 表头对齐严密，表格行间距更舒展，支持直接拖拽调整动作先后顺序。
3. **右侧深度巡视器 (Contextual Inspector - 400~460px 固宽)**：
   - **自适应上下文联动**：鼠标点击左侧哪个动作，右侧立即联动刷新该动作的专属情报：
     - **超负荷推算卡片**：自动与上周数据做 Diff 比对；
     - **杠铃片可视化计算器**：常驻展示当前组重量的单边插片示意图，免去弹窗遮挡；
     - **历史 1RM 趋势图**：直观展示过去 3 个月该动作的最高负重跃升曲线。

## 五、 组件设计规范与微动效 (Atoms & Interactions)

### 5.1 触控与交互按钮 (Buttons & Controls)

```
Primary Action        Secondary / Step      Checkmark Button (48px)     PR Badge Pop
+------------------+  +------------------+  +-----------------------+   +------------+
| ⚡ 开始训练      |  |  -2.5kg    +2.5kg|  |         [ ✓ ]         |   | 🏆 NEW PR! |
+------------------+  +------------------+  +-----------------------+   +------------+
#22c55e (Neon Green)  #1a1e29 (Dark Surface) 默认浅框，勾选瞬间高亮微缩放  电金发光徽章
```

1. **打卡勾选按钮 (The Hero Checkmark)**：
   - 尺寸：严格遵循 $\ge 48\text{px} \times 48\text{px}$；
   - 默认态：暗色半透明背景 `rgba(255,255,255,0.05)`，细微边框 `1px solid var(--border-subtle)`；
   - 勾选完成态：背景瞬间转为鲜亮荧光绿 `#22c55e`，图标颜色反转为深黑 `#07080b`，伴随 `scale(0.92) -> scale(1.05) -> scale(1)` 弹簧微动效；
   - 破纪录态：右上角弹出带光芒波纹的金色 `PR` 徽章。
2. **快速步进调节器 (Precision Steppers)**：
   - 摒弃原生系统粗糙的上下微调小箭头；
   - 采用扁平胶囊步进钮（`+2.5`, `-2.5`, `+1`, `-1`），点击拥有震动与数字瞬间递增动效。

### 5.2 全局悬浮组件规范 (Floating Widgets)

1. **悬浮倒计时栏 (Docked Rest Bar)**：
   - 桌面端：固定停靠在右下角或顶部常驻状态条中，不阻挡操作视线；
   - 移动端：底部贴合悬浮，带 1px 荧光绿动态进度条走线，支持轻滑跳过；
   - 视觉质感：高模糊毛玻璃 `rgba(16, 18, 24, 0.88)` + 40px 阴影扩散。
2. **杠铃片可视化插片规范 (Barbell Sleeve Rendering)**：
   - 严格遵循国际举重/力量举标准色标：
     - $25\text{kg}$：正红 `#EF4444`（高度 $76\text{px}$）
     - $20\text{kg}$：海蓝 `#3B82F6`（高度 $72\text{px}$）
     - $15\text{kg}$：暖黄 `#EAB308`（高度 $66\text{px}$）
     - $10\text{kg}$：草绿 `#22C55E`（高度 $60\text{px}$）
     - $5\text{kg}$：纯白 `#F8FAFC`（高度 $50\text{px}$，字体反转为黑色）
     - $2.5\text{kg}$：铁黑 `#1E293B`（高度 $42\text{px}$）
     - $1.25\text{kg}$：冷灰 `#94A3B8`（高度 $36\text{px}$）

## 七、 样式文档维护与落地检查表

为确保后续 Phase 2（数据可视化）、Phase 3（智能超负荷推算）及 Phase 4 研发中团队遵循本套规范，制定如下设计检查原则：

- [ ] **拒绝随意编写无序 HEX 颜色**：所有颜色必须引用 `--bg-*`、`--accent-*` 或 `--text-*` 语义变量；
- [ ] **大屏视口利用率检查**：桌面宽度 $>1024\text{px}$ 时，页面不得出现超过 300px 的无意义空白两翼，必须采用分栏工作台布局；
- [ ] **所有数字必须 Tabular 对齐**：任何重量、组数、次数、倒计时均须应用 `var(--font-mono)` 或 `font-variant-numeric: tabular-nums`；
- [ ] **触控面积不得劣化**：移动端所有可点击元件最小边界严禁小于 $44\text{px}$（打卡核心大按钮必须保持 $48\text{px}$）。
