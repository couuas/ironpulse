## 一、 阶段研发目标与交付物范围

本阶段核心目标是构建兼具**“体态全生命周期监测”**与**“数据自主所有权”**的发布级成熟平台，并将应用转化为具备原生 App 体验的离线 PWA 容器。

### 交付物清单
1. **T4.1 体重平滑趋势与多点位身体围度追踪系统 (Body Metrics & 7-Day Moving Average)**：
   - 建立 `BodyMeasurement` 数据模型与 Dexie version(2) 数据表平滑升级；
   - 7-Day Moving Average (7MA) 平滑降噪算法，消除每日水钠波动干扰，提供 7 天净变化与 30 天长期趋势；
   - 纯声明式 SVG 双轨走势图（每日散点折线 + 7MA 平滑发光曲线）与多点位围度（胸、腰、臀、臂、腿）追踪面板。
2. **T4.2 数据完全自主权：全量结构化 JSON / CSV 导出与恢复系统 (Data Sovereignty)**：
   - 结构化 JSON 全量备份导出（覆盖动作库、模板、历史训练、训练组、PR 记录与体态指标全部 6 张表完整数据）；
   - 清洗型 CSV 扁平化导出（携带完整训练字段与 UTF-8 BOM，原生兼容 Excel / WPS / Python 数据分析）；
   - JSON 备份无损恢复与校验引擎（支持合并模式与覆盖模式，内置 Schema 防损容错）；
   - 出厂重置与危险操作防手抖安全确认机制。
3. **T4.3 PWA 离线容器化与独立应用安装体验 (Progressive Web App)**：
   - `manifest.webmanifest` 配置文件，定义全屏独立窗口 `display: standalone` 与暗影精密深色主题；
   - 原生 Service Worker 缓存 App Shell 与核心静态资源，地下室弱网环境下 100% 离线秒开；
   - 原生应用安装提示组件 (`PWAInstallBanner`) 与离线守护。
