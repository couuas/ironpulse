## 一、 阶段研发目标与交付物范围

本阶段核心目标是构建科学、精密的力量训练**数据深化与生理负荷视觉化系统**。基于过去 7 天内的实际打卡负荷，计算人体各肌群的“有效硬组数 (Hard Sets)”，以纯矢量解剖图的形式呈现肌群疲劳/恢复状态；同时构建 1RM 极限预测曲线探索器、个人 PR 荣誉殿堂，并在桌面端提供高密度的专业数据分析工作台。

### 交付物清单
1. **T2.1 极限推算与 1RM 趋势曲线探索器**：
   - 基于 Epley 阻尼衰减修正公式的历次训练 1RM 极值提取算法；
   - 纯声明式 SVG 平滑贝塞尔面积图，支持动作自由切换、时间坐标系缩放、数据点光斑游标与增长率分析；
   - 现场打卡联动：在 Active Workout 桌面端 Live Inspector 中内嵌该动作的历史 1RM 微缩走势图。
2. **T2.2 交互式人体解剖肌群负荷热力图 (Human Muscle Heatmap)**：
   - 纯矢量高精度解剖人体双视角（前面观 Anterior + 后面观 Posterior）；
   - 涵盖 11 大核心肌群（胸、肩、二头、三头、背阔、斜方、核心/腹肌、臀、股四、腘绳、小腿）；
   - 动态生理负荷算法（主肌群 1.0 权重，协同肌群 0.5 权重，过滤非有效热身组）；
   - 4 级状态色彩映射阶梯（0-4 组恢复冷色，5-9 组维持蓝青，10-18 组黄金增肌绿，$\ge 19$ 组疲劳预警红）；
   - 点击肌群支持联动高亮与关联动作训练量明细下钻。
3. **T2.3 个人 PR 荣誉殿堂 (PR Milestone Shelf)**：
   - 力量举三大项（深蹲、卧推、硬拉）综合总成绩（Big Three Total）与单项突破汇总；
   - 动作级历史巅峰纪录卡片网格，展示最高负重、推算 1RM、达成日期与徽章动效。
4. **T2.4 桌面端高密度分析工作台 (`/analytics`)**：
   - 整合解剖热力图、1RM 曲线探索器、PR 殿堂与周度训练负荷分布柱状图；
   - 桌面大屏（$\ge 1024\text{px}$）双列分屏高密排版，自适应响应式无横向溢出。

## 二、 阶段验收标准一：代码审查清单 (Code Review Checklist)

- [x] **1. 算法与数学计算边界**：
  - [x] 1RM 算法严格采用 `calculateEpley1RM`，次数=1 时恒等于自身重量，次数>15 时加入阻尼衰减系数（0.4），杜绝耐力组推算虚高；
  - [x] 7 日肌群负荷计算处理空数据与边缘跨周时间戳，杜绝 `NaN` 与负数组数；
  - [x] 主肌群按 1.0 组计，辅助肌群按 0.5 组计，热身组（warmup）不计入有效硬组数。
- [x] **2. 架构与依赖轻量化 (Zero-Dependency SVG)**：
  - [x] 热力图与面积图完全基于声明式 SVG 实现，零引入庞大外部图表库，全包构建 gzip 增量仅 11KB；
  - [x] 人体矢量路径（path）语义清晰、布局规整，所有渐变 `defs` 拥有防冲突唯一 ID；
  - [x] SVG 具有自适应 `viewBox`，在不同分辨率与移动端屏幕下等比缩放不失真。
- [x] **3. 状态管理与存储性能**：
  - [x] 统计聚合计算在读取 IndexedDB 历史后利用 `useMemo` 缓存，避免无关状态变化引发重复遍历；
  - [x] 切换动作或时间窗口时交互延迟感知为 0ms。
- [x] **4. 生产构建规范**：
  - [x] 执行 `npm run build`（`tsc -b && vite build`），0 警告、0 错误，打包耗时 1.66s。

## 四、 阶段验收标准三：人工实测走查流程 (Manual Acceptance Workflow)

### 第一幕：破纪录与 1RM 走势联动实测 (Happy Path PR Trend)
- **操作记录**：进入“分化计划”发起一次推力日训练 $\rightarrow$ 卧推打卡 100kg × 6（等效 1RM 达 120kg，创历史新高） $\rightarrow$ 结算训练 $\rightarrow$ 切换至“数据分析”工作台。
- **实测判定**：**通过**。1RM 趋势曲线立即呈现平滑上升走势，各历史点位可悬停查看日期与实测负荷；三大项 SBD 看板卧推单项更新至 120kg，PR 荣誉殿堂同步点亮卧推新纪录卡片。

### 第二幕：肌群热力图负荷跃迁实测 (Heatmap Color Transitions)
- **操作记录**：在未训练状态下（各肌群呈冷灰恢复色），结算一组包含 12 组背部动作（高位下拉 + 杠铃划船）的训练 $\rightarrow$ 进入数据分析查看后面观。
- **实测判定**：**通过**。后面观背阔肌与斜方肌从冷灰色平滑跃迁为高能荧光绿（10-18 组增肌黄金区间），二头肌获得辅助加权（6组）转为维持蓝，点击背部区域展开贡献动作清单明细。

### 第三幕：桌面大屏与跨端布局走查 (Cross-Device Workstation)
- **操作记录**：在 1440px 桌面端全屏展开工作台，测试肌群点击联动与动作下拉切换；将视口缩窄至 375px 移动端尺寸，测试折叠展示。
- **实测判定**：**通过**。桌面端左右双列网格无水平溢出，移动端热力图与走势图自适应收拢，触控点击靶心适中。
